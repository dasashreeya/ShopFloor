# Design System

## Brand & Style
The design system adopts a **Corporate / Modern** style, characterized by a reliable, balanced, and professional aesthetic inspired by modern enterprise design frameworks. It evokes trust, clarity, and efficiency, making it ideal for data-dense applications and professional workflows.

## Colors
The color palette is built for clarity and focus. 
- **Primary Color (`#1234e3`)**: A strong, professional blue used for key interactive elements, primary actions, and brand anchors.
- **Secondary Color (`#99a9c6`)**: A muted slate blue-gray used for supportive UI elements, borders, and secondary states.
- **Tertiary Color (`#000000`)**: Deep black utilized for high-contrast text and critical structural accents.
- **Neutral Color (`#fefefe`)**: Clean, near-white neutral backgrounds ensuring maximum readability and a spacious canvas.

## Typography
The typography system uses **Inter** exclusively across headlines, body text, and labels. Inter provides exceptional legibility at all sizes, maintaining clean geometric lines that reinforce the professional, modern tone of the system.

## Layout & Spacing
Using a structured grid model with a balanced spacing scale, layouts prioritize clear alignment and generous whitespace. Margins and gutters scale predictably across viewports to maintain structural rhythm.

## Elevation & Depth
Elevation is achieved primarily through tonal layering and clean, low-contrast outlines rather than heavy drop shadows, aligning with modern enterprise software standards.

## Shapes
The shape language uses **Rounded** corners (roundedness level 2). UI elements feature a standard 0.5rem border radius, with larger containers scaling up to 1rem and 1.5rem, offering an approachable yet professional feel.

## Components
Components follow the defined Inter typography, rounded shape tokens, and primary blue interactive styling to ensure consistent patterns across buttons, inputs, cards, and navigation elements.
