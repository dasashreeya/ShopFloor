# Recommendation evaluation

Generated by `scripts/evaluate.py`. **Personas are evaluation fixtures** (plausible owner inputs, written before tuning), not real businesses. Tool data is the real catalog in `shopfloor/catalog/tools.json`.

11 personas × 4 jobs = 44 recommendations per method.

| Method | Breaks an owner's hard rule (software, industry, budget, must-have) | Recommends a purchase that loses money (by our own estimate) | Ignores a free built-in the owner already has | Recommends without the data to justify it |
|---|---|---|---|---|
| ShopFloor | 0 / 44 | 0 / 44 | 0 / 44 | 0 / 44 |
| Top-rated | 13 / 44 | 4 / 44 | 16 / 44 | 16 / 44 |
| Cheapest | 23 / 44 | 10 / 44 | 16 / 44 | 16 / 44 |

ShopFloor's zeros hold by construction: hard rules run before scoring and 'don't buy' and 'need data' are allowed answers. The baselines show how often a ratings-first or price-first choice would mislead these owners.

Limits: value is judged by our own estimator, so 'loses money' is relative to our assumptions (see Research). The real test is the 16-week pilot: owner check-ins against these predictions.
